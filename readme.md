# Video Segments Calculator

_Made to simplify YaaziCut segment calculations._

**[▶️ LIVE PREVIEW](https://itslokeshx.github.io/Segment-calculator/)**

</div>

---

A minimal web tool for YaaziCut users:
- Enter your video duration (hours, minutes, seconds)
- Select your segment size & unit
- Instantly get your segment count

> **No install needed. Works everywhere.**



**Example:**  
2 hours, split into 30-second segments = **240 segments**
